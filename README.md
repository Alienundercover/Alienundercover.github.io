# Plastic Fantastic

A GitHub Pages project for learning and testing HTML and CSS.

## Project Overview

This is a simple portfolio website built to practice web development fundamentals including HTML structure and CSS styling.

## Pages

- **Home** - Main landing page
- **About** - Information page
- **Services** - Services overview
- **Gallery** - Image gallery
- **Contacts** - Contact information
- **Nerd Quotes** - Fun quotes section

## Technologies

- **HTML5** (38.8%)
- **CSS3** (61.2%)

## Purpose

Testing GitHub Pages deployment and strengthening HTML/CSS skills through hands-on project development.
